# Desafio 12 - Cadastro de produtos completo

Evolua o exemplo `ProjetoFinal.dpr`.

## Requisitos obrigatorios

- Criar um menu com `case`.
- Opcao 1: cadastrar produto.
- Opcao 2: listar produtos.
- Opcao 3: salvar em arquivo.
- Opcao 4: sair.
- Usar `repeat/until` para repetir o menu ate sair.
- Validar preco maior que zero.
- Validar estoque maior ou igual a zero.

## Requisitos de organizacao

- Crie uma procedure para mostrar o menu.
- Crie uma procedure para cadastrar.
- Crie uma procedure para listar.
- Crie uma function para calcular valor total do estoque.
- Use nomes claros.

## Extra

Separe o record e as regras em uma unit `UProdutos.pas`. Deixe o `.dpr` apenas
com o fluxo principal do menu.
