# Desafio 05 - Tratador de texto

Crie um programa com uma variavel `NomeCompleto`.

## Requisitos

- Remova espacos das pontas usando `Trim`.
- Mostre o nome em maiusculo.
- Mostre o nome em minusculo.
- Mostre o total de caracteres.
- Descubra se existe espaco no nome usando `Pos`.
- Se existir espaco, mostre o primeiro nome usando `Copy`.

## Extra

Crie uma string `IdadeTexto`. Converta com `StrToIntDef`. Se a conversao falhar,
mostre idade `0`.
