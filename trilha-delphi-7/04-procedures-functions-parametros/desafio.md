# Desafio 04 - Biblioteca de calculos

Crie um programa com as seguintes functions:

- `Somar(A, B: Integer): Integer`
- `Subtrair(A, B: Integer): Integer`
- `Multiplicar(A, B: Integer): Integer`
- `Dividir(A, B: Double): Double`
- `EhPar(Valor: Integer): Boolean`

## Requisitos

- Chame todas as functions no bloco principal.
- Mostre os resultados na tela.
- Na divisao, se `B = 0`, retorne `0` por enquanto.

## Extra

Crie uma procedure `MostrarResultado(const Nome: string; Valor: Double)` para
padronizar a saida.
