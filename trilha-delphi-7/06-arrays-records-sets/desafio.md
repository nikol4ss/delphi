# Desafio 06 - Cadastro de alunos em memoria

Crie um programa com um record `TAluno`.

## Campos

- `Nome: string`
- `Nota1: Double`
- `Nota2: Double`
- `Nota3: Double`
- `Media: Double`

## Requisitos

- Crie um array estatico com 3 alunos.
- Preencha os dados manualmente no codigo.
- Calcule a media de cada aluno.
- Mostre o nome e a media de cada aluno usando `for`.
- Mostre `Aprovado`, `Recuperacao` ou `Reprovado`.

## Extra

Crie um enum `TStatusAluno` e guarde o status dentro do record.
