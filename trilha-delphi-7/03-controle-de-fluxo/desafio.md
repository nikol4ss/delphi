# Desafio 03 - Menu de notas

Crie um programa console com uma variavel `Opcao`.

## Requisitos

- Se `Opcao = 1`, calcule a media de 3 notas.
- Se `Opcao = 2`, mostre uma contagem de 1 ate 10.
- Se `Opcao = 3`, mostre `Saindo`.
- Para qualquer outro valor, mostre `Opcao invalida`.
- Use `case`.

## Extra

Depois de calcular a media, use `if/else` para mostrar:

- `Aprovado` se media >= 7.
- `Recuperacao` se media >= 5 e menor que 7.
- `Reprovado` se media < 5.
